# Agent marks

Harness avatars use local SVGs so they render offline.

- `claude.svg`, `codex.svg`, `gemini.svg`, `kimi.svg`, `opencode.svg`, and `pi.svg` come from [theSVG](https://thesvg.org/).
- `aider.svg` comes from Aider's official `safari-pinned-tab.svg`; its fill uses Aider green (`#14b014`).
- Monochrome marks use Slirc's text color so they stay visible on its dark surface.
- `agent.svg` is Lucide's `bot` icon (ISC), the mark for an agent whose harness has no logo here.
- `*-light.svg` files are the same marks in the light theme's text color; `style.css` swaps them in.

Brand names and marks belong to their respective owners.
