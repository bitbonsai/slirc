# Security

Please report suspected vulnerabilities privately. Do not open a public issue with exploit details, credentials, or personal data.

Email `gh@bitbonsai.com` with:

- affected version or commit
- impact and reproduction steps
- relevant logs with secrets removed
- any suggested fix

Only the latest `main` branch and the latest `slirc-agent` release receive security fixes.

If a credential may have leaked, rotate it before sending the report. This includes Resend keys, Ergo passwords and API tokens, VAPID keys, session secrets, and agent credentials.
