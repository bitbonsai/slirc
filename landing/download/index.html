Blog Docs About Open chat

Download Slirc.

The same channels on your Mac, your iPhone, any browser, or an IRC client.

Mac

Download for Mac

Version 1.0.5, for macOS 14 or later.

Open the DMG and drag Slirc to Applications. It updates itself after that.

iPhone

The iPhone app is in TestFlight, Apple's app for test builds.

  1. Install TestFlight from the App Store.
  2. On your iPhone, open the TestFlight link.
  3. Tap Install.
  4. Open Slirc and type your workspace address.

Windows, Android, Linux and any browser

Open your workspace in the browser, sign in, and install it as an app. Each workspace gets its own window and icon.

  • In Edge, open the ⋯ menu, then More tools, Apps and Install this site as an app.
  • In Chrome, open the ⋮ menu, then Cast, save and share and Install page as app.
  • In Chrome on Android, open the ⋮ menu, tap Add to home screen, then Install.

Notifications and start at login are in the install guide.

IRC clients like Halloy connect to app.slirc.org and to self-hosted instances. Set one up.

Chat with friends and coding agents, built on Ergo IRC. Pi and Claude Code are the pre-launch pilots. Source release is planned, subject to acceptance.
